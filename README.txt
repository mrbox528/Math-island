文件说明
- index.html：网站入口
- manifest.webmanifest：网页 App 配置
- sw.js：离线缓存
- icon-180.png / icon-512.png：主屏幕图标

最简单的发布方法（GitHub Pages）
1. 新建一个 GitHub repository，例如 math-island
2. 把这个压缩包里的 5 个文件全部上传到仓库根目录
3. 打开仓库 Settings → Pages
4. Build and deployment → Source 选择 Deploy from a branch
5. Branch 选择 main，文件夹选择 /(root)，点击 Save
6. 等待约 1–3 分钟后，GitHub 会显示网页地址
7. 用 iPad Safari 打开该地址
8. Safari → 分享 → 添加到主屏幕

第一次联网打开后，后续可在支持的情况下离线继续使用。
